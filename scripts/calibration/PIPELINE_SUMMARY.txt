CAPABILITIES
------------
1. Calibration Data Preparation
   - Selects 800-1000 diverse training images
   - Ensures class distribution coverage
   - Handles variable image sizes
   - Creates calibration manifest with statistics

2. Custom TensorRT Calibrator
   - IInt8EntropyCalibrator2 implementation
   - Batch processing (configurable batch size)
   - Calibration cache support (reusable)
   - Multiple preprocessing modes (standard, letterbox)
   - Progress reporting

3. TensorRT Engine Builder
   - Loads and validates ONNX models
   - Applies INT8 calibration
   - Mixed precision support (FP16 detection heads)
   - Builds optimized engines (FP32, FP16, INT8)
   - Timing cache for faster rebuilds
   - Detailed layer precision logging

4. Accuracy Validation
   - Side-by-side FP32 vs INT8 comparison
   - Calculates mAP and degradation percentage
   - Per-class accuracy analysis
   - Identifies problematic classes
   - Generates JSON validation reports

5. Performance Benchmarking
   - Latency measurement (mean, P50, P95, P99)
   - Throughput measurement (FPS)
   - GPU memory usage profiling
   - Power consumption estimation
   - Multi-engine comparison mode
   - Target validation (55 FPS, <2% mAP loss)

6. End-to-End Automation
   - Complete pipeline in one command
   - Preflight system checks
   - Progress tracking and reporting
   - Error handling and recovery
   - Comprehensive markdown report generation
   - Color-coded terminal output

USAGE
-----
Quick Start:
    cd /home/user/BAHB/scripts/calibration
    ./check_setup.py              # Verify prerequisites
    ./run_full_pipeline.sh        # Run complete pipeline

Individual Scripts:
    # Prepare calibration data
    python3 prepare_calibration_data.py --num-images 1000

    # Build INT8 engine
    python3 build_engine.py --precision int8 \
        --onnx model.onnx \
        --engine model_int8.engine \
        --calibration-manifest calibration_manifest.json

    # Validate accuracy
    python3 validate_accuracy.py \
        --fp32-engine model_fp32.engine \
        --int8-engine model_int8.engine

    # Benchmark performance
    python3 benchmark.py --engine model_int8.engine
