QUICK START
-----------
1. Run installer:
   $ cd /home/user/BAHB/deployment
   $ sudo ./install.sh

2. Copy model files:
   $ sudo cp *.engine /home/user/BAHB/deployment/models/

3. Configure environment:
   $ cp .env.example .env
   $ nano .env

4. Start services:
   $ make up

5. Verify deployment:
   $ sudo ./verify_deployment.sh

6. View logs:
   $ make logs

ESSENTIAL COMMANDS
------------------
Installation:
  sudo ./install.sh

Start/Stop:
  make up          or  sudo systemctl start bahb
  make down        or  sudo systemctl stop bahb
  make restart     or  sudo systemctl restart bahb

Monitoring:
  make logs        - View all logs
  make logs-bahb   - BAHB main only
  make status      - Service status
  make health      - Health checks

Verification:
  sudo ./verify_deployment.sh

Performance:
  make optimize    - Set MAXN mode
  make stats       - Resource usage

Maintenance:
  make backup      - Backup data
  make clean       - Clean up
  make update      - Update BAHB

Help:
  make help        - Show all commands
