# Jinki Intelligence

Premium landing page for Jinki Intelligence - AI-powered aerial risk intelligence for Virginia data center infrastructure.

## Website

Located in `jinki-landing-showcase/`

```bash
cd jinki-landing-showcase
npm install
npm run dev
```

## Features

- Cinematic preloader with liquid metal progress
- 6-layer 3D parallax system
- GSAP ScrollTrigger animations
- Lenis smooth scroll
- Custom magnetic cursor
- Premium glassmorphism (7-layer)
- Liquid metal chrome effects

## Deploy

```bash
cd jinki-landing-showcase
npx vercel --prod
```
