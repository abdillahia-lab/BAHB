THE OPPORTUNITY
═══════════════════════════════════════════════════════════════════════════════

Jinki Intelligence's B2B landing page loads 57 kB of Three.js code for EVERY
visitor, even though 90% of them only visit the homepage.

This creates a performance penalty:
  • LCP: 3.8 seconds (vs 2.0s industry best)
  • Core Web Vitals: 62/100 (Poor)
  • Enterprise customers: "Why is this slow?"


THE SOLUTION
═══════════════════════════════════════════════════════════════════════════════

Use React 18's lazy() + Suspense to defer Three.js until users navigate to
3D showcase pages.

Result:
  • Homepage-only visitors skip 57 kB of unnecessary code
  • 3D page visitors get a nice loading skeleton + fast transition
  • Zero breaking changes, zero new dependencies


THE RESULTS
