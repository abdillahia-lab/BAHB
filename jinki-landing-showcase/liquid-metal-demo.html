Technical Features - .liquid-metal

  • 26-stop conic + linear gradient blend for ultra-realistic chrome
  • Black reflection lines (#0a0a0a, #1a1a1a, #2a2a2a) for depth
  • Dual animation system: metalShimmerAdvanced (4s) + metalRotate (12s)
  • 13-layer box-shadow system: inset bevels + edge depth + outer glow
  • Dynamic filter adjustments: brightness(1.05) contrast(1.1)
  • Two animated pseudo-elements: fast gleam sweep + environment rotation

2. Interactive States - Click & Tab

Advanced interactive feedback with hover shimmer speed increase, active state compression, and focus chromatic aberration effects.

Interactive States Breakdown

  • :hover - Shimmer speed 40% faster, brightness +10%, lifted 2px
  • :active - Compressed depth, scale(0.98), brightness -10%
  • :focus-visible - RGB split glow (chromatic aberration effect)
  • ::before animation - Dual gleam sweep at different speeds
  • ::after opacity - Environment map fades in on hover

Performance Optimizations

  • Hardware acceleration: transform: translateZ(0) on animated layers
  • will-change: background-position on ::before for smooth gleam
  • Reduced motion support: All animations disabled via @media query
  • Isolation: isolate prevents blend-mode performance issues
  • Mix-blend-mode: overlay/screen for realistic metal reflections
  • Optimized keyframes: Using background-position instead of transforms

Complete Technical Specifications

  • Gradients: Conic (26 stops) + Linear (17 stops) with blend-mode
  • Animations: 5 keyframes (shimmer, rotate, gleam x2, environment)
  • Box Shadows: 13 layers (8 inset, 5 outer)
  • Filters: brightness, contrast, drop-shadow (6 layers on text)
  • Pseudo-elements: ::before (gleam), ::after (environment map)
  • Interactive States: hover, active, focus-visible with unique effects
