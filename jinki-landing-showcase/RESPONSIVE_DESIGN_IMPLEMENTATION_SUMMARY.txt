================================================================================
                          KEY IMPLEMENTATION DETAILS
================================================================================

CSS CLAMP FORMULA:
  clamp(minimum, preferred, maximum)

  Example: clamp(2.5rem, 6vw, 4rem)
  ├─ 320px: Uses 2.5rem (minimum)
  ├─ 768px: Uses 46px (6% of viewport)
  ├─ 1920px: Uses 4rem (maximum)
  └─ Scales smoothly in between

CONTAINER QUERY EXAMPLE:
  @container industry-card (min-width: 350px) {
    .card__label { font-size: 0.6875rem; }
  }

  Component adapts when ITS width > 350px
  Not dependent on viewport width

MOBILE-FIRST CASCADE:
  1. Base styles (mobile: 320px+)
  2. Tablet enhancement @media (min-width: 768px)
  3. Desktop enhancement @media (min-width: 1200px)
  4. Ultra-wide enhancement @media (min-width: 1920px)

TOUCH VS MOUSE:
  @media (pointer: coarse) { /* Touch */ }
  @media (pointer: fine) { /* Mouse */ }

  Different interactions, smooth experience
