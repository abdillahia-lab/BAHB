### I want to...

**Transform ASCII to rendered image**
```javascript
const { transform } = useAsciiToRendered();
await transform(asciiEl, imageEl);
```
→ See: `src/snippets/MORPHEUS_READY_TO_USE.md` Snippet 1

**Create a section carousel**
```javascript
const { applyPortal } = usePortalTransition();
await applyPortal(sectionEl, 'forward');
```
→ See: `src/snippets/MORPHEUS_READY_TO_USE.md` Snippet 2

**Morph elements on scroll**
```javascript
const morphRef = useScrollMorphing({ duration: 800 });
```

→ See: `src/snippets/MORPHEUS_READY_TO_USE.md` Snippet 5

## 🔗 Integration Steps

1. **Copy Core Files:**
   ```bash
   cp src/utils/advancedTransitions.js your-project/src/utils/
   cp src/styles/morpheusTransitions.css your-project/src/styles/
   cp src/hooks/useMorpheusTransition.js your-project/src/hooks/
   ```

2. **Import CSS:**
   ```jsx
   import '@/styles/morpheusTransitions.css';
   ```

3. **Use Hooks in Components:**
   ```jsx
   const { execute } = useMorphTransition();
   const { applyPortal } = usePortalTransition();
   const morphRef = useScrollMorphing();
   ```

4. **Or Use CSS Classes:**
   ```html
   <div class="transition-liquid">Content</div>
   ```

5. **Test:**
   ```bash
   npm run dev
   # Open in Chrome 111+
   # Enjoy smooth 60 FPS transitions!
   ```
