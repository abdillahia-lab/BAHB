🧠 CONFUSION DETECTION SYSTEM
════════════════════════════════════════════════════════════════════════════

6 BEHAVIORAL SIGNALS AUTOMATICALLY DETECTED:

1. RAPID_SCROLL
   • Threshold: 5 scroll events in 2 seconds
   • Confidence: 0.6
   • Response: "Try scrolling slower" suggestion

2. BACK_FORTH_SCROLL
   • Threshold: 3+ direction changes in 5 seconds
   • Confidence: 0.7
   • Response: "Use navigation menu" suggestion

3. IDLE_ON_SECTION
   • Threshold: 8 seconds without interaction
   • Confidence: 0.5
   • Response: "Try clicking on elements" suggestion

4. HOVER_WITHOUT_ACTION
   • Threshold: 3+ hovers in 5 seconds
   • Confidence: 0.4
   • Response: "Click to interact" suggestion

5. CLICK_HUNTING
   • Threshold: 3+ clicks on same element
   • Confidence: 0.8
   • Response: "Try a different element" suggestion

6. FORM_HESITATION
   • Threshold: 3+ seconds focused without typing
   • Confidence: 0.7
   • Response: Field-specific hint

════════════════════════════════════════════════════════════════════════════
⚙️ TIMING & FREQUENCY RULES
════════════════════════════════════════════════════════════════════════════

GLOBAL RULES:
• Max 1 help showing at a time (never overwhelm)
• Minimum 5 seconds gap between helps
• Maximum 8 helps per session (avoid fatigue)
• Respects flow state (doesn't interrupt smooth scrolling)

DEVICE-SPECIFIC TIMING:
• Mobile:    1.5x longer delays, 6 second timeout
• Tablet:    1.2x longer delays, 8 second timeout
• Desktop:   1.0x normal delays, 10 second timeout

USER EXPERIENCE ADAPTATION:
• First visit:  100% help frequency (show everything)
• Returning:     60% help frequency (less often)
• Regular:       30% help frequency (minimal)

LEARNING RULES:
• 80%+ engagement      → show_more_help
• 30-80% engagement    → show_normal_help
• <30% engagement      → show_less_help
