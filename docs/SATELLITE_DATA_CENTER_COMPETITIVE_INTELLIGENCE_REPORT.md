### Methodology Deep Dive

#### Cooling Capacity Model
```
Total Facility Power = (Capacity per Cooling Unit × Number of Units / Cooling Overhead) × Peak PUE
```

#### AI Chip Model
```
Total Facility Power = Chip Quantity × Server Power per Chip × IT Overhead × Peak PUE
Performance = Chip Quantity × Performance per Chip
```

#### Capital Cost Model
- **$44B per GW** of server power
  - $30B hardware
  - $14B infrastructure
- Total facility power equivalent: ~$29B/GW

### Accuracy & Confidence
- **80% confidence** metrics within 1.5× factor (66-150% of actual)
- Six independent methods cross-validated for key facilities
- Example: Stargate Abilene estimates ranged 139-190 MW, converged to 147 MW

### Current Coverage
- **13 US data centers** tracked
- **~2.5M H100e** operational capacity (~15% global AI compute)
- Facilities: OpenAI, Google DeepMind, Meta, Anthropic, xAI
