## ANIMATION DETAILS

### Badge Load Animation
```
Initial State:
  - opacity: 0
  - y: 20px (below final position)

Final State:
  - opacity: 1
  - y: 0

Trigger: When badge enters viewport
Duration: 0.5s
Easing: default Framer Motion (ease-out)
Stagger: Each badge +0.1s delay
```

### Hover Animation
```
Hover Start:
  - Scale: 1 → 1.05
  - Glow: off → on
  - Duration: 0.3s

Hover End:
  - Scale: 1.05 → 1
  - Glow: on → off
  - Duration: 0.2s
```

```
Initial: opacity 0
Animate: opacity 1
Transition: 0.2s
Timing: On hover start
```

## PERFORMANCE INDICATORS

### Load Sequence
1. **Critical path** (hero, industries, platform): Load normally
2. **Trust Stack Footer**: Lazy-loaded when scrolling approaches
3. **Badges**: SVG badges, <5KB total
4. **API data** (uptime): Fetched async, non-blocking
5. **Fallback**: Shows cached/static values if API slow

### Bundle Impact
```
TrustStackFooter.jsx:        ~2KB
TrustStackBadge.jsx:          ~1.5KB
StatusBridge.jsx:             ~1.5KB
SecurityScanResults.jsx:      ~1KB
TrustStack.css:               ~3KB
─────────────────────────────────
Total Added:                  ~9KB (minified)
Current Bundle:               ~180KB
Impact:                       +5% (negligible)
```
